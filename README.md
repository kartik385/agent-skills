# Agent skills

Personal reusable skills for coding agents.

## Contents

The skills live in `.agents/skills/`. Each skill is a complete directory and may include references or helper files in addition to `SKILL.md`.

## Use in another project

Copy the required skill directories into that project's `.agents/skills/` directory, then commit them with the project if the team should share the same workflow.

This repository intentionally excludes plugin-managed and built-in skills. Install those separately in each Codex environment.
